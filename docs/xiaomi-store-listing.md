## 应用简介（≤ 500 字）

颜 Studio 是一款把「拍好」和「修好」放在一起的影像工具。

拍摄时有实时构图辅助：九宫格、水平仪、机位角度提示，帮你在按下快门前就把画面结构定下来。专业模式支持手动对焦、曝光与白平衡，用手机也能拍出可控的画面。

拍完不用换 App：裁剪、调色、模板套用、文字水印一站完成；作品与草稿自动收进本地作品库，随时找回、对比、再编辑。

AI 能力是可选的进阶项：你可以填入自己的 MiniMax / DeepSeek API Key，在手机上直接完成文生图、风格迁移与提示词优化，不需要把照片上传到第三方服务器。所有 AI 生成内容都会保留「AI 生成」标识。

我们把「本地优先」写进了设计里：照片、编辑结果、作品记录只保存在你的手机中，不上传、不注册、不需要账号；卸载 App 或在设置中清除本地作品，数据即刻从设备移除。

主要功能：
· 实时构图辅助与专业拍摄模式
· 本地图片编辑：裁剪、调色、模板、水印
· 作品库、收藏与草稿
· 一键排版分享，导出保留 AI 标识
· 可选 BYOK AI 生成（自备 API Key）
