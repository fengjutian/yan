# 灵感与工作室模块优化

> 范围：`apps/mobile` 的「灵感」与「工作室」两个一级入口。  
> 目标：在本地优先、不依赖后端的前提下，缩短「看到灵感 → 选一张照片 → 开始创作 → 看见成果」的路径。

## 1. 优化前的问题

- 灵感首页只有静态推荐，没有搜索入口、最近创作和风格入口。
- 灵感模板页只有分类筛选，没有搜索和排序；收藏面板在回调里 `ref.watch`，存在 Riverpod 生命周期风险。
- 模板只能进入相机，无法直接套用推荐风格进入工作室。
- 工作室是一个静态功能列表：不展示相机来源照片、不展示最近作品、不能从相册直接导入并选择编辑方式。
- 风格迁移页只能被动接收相机照片；从首页/模板进入时没有照片就无法继续。
- 模板收藏依赖 `sharedPreferencesProvider` 同步就绪，首次打开模板页可能因 preferences 尚未加载而抛错。

## 2. 灵感模块

### 2.1 灵感首页

- 新增搜索入口：点击进入模板页并自动聚焦搜索框。
- 新增「最近创作」：读取本地作品库，有作品时展示横向缩略图；空库时整段隐藏，避免首屏拥挤。
- 新增「热门风格」：展示本地风格预设，点击后直接带着风格进入风格迁移页，由迁移页选照片。
- 「今日灵感」改为根据精选模板与日期轮换构图建议，不再写死一条文案。

### 2.2 灵感模板页

- 本地即时搜索：匹配标题、副标题、分类、标签和推荐风格 id。
- 排序：推荐、最热、名称、收藏优先。
- 收藏面板重写为独立的 `ConsumerWidget`，从 `allTemplatesProvider` 取模板，支持取消收藏和直接打开详情。
- 空搜索结果、加载失败、分类为空都有独立状态与恢复入口。
- 卡片、搜索框、排序菜单改用主题色，修复深色模式下的白色卡片问题。
- 搜索时隐藏精选 banner，把首屏留给结果。

### 2.3 模板详情

- 保留「用此模板拍」，新增「用示例灵感创作」，把示例 Prompt 带入文生图页。
- 推荐风格变为可点击：点击后带推荐风格进入风格迁移页，由用户补一张照片即可套用。
- 增加模板热度展示。

## 3. 工作室模块

### 3.1 一屏工作台

- 顶部来源卡：
  - 相机有选中照片时，全幅展示成片、质量标签与「AI 风格迁移」入口；
  - 多张候选照片时提供横向缩略图切换；
  - 没有照片时展示「从相册导入 / 去拍一张」两个入口。
- 快捷工具 2×2：图片编辑器、导入照片、AI 图像创作、我的作品。
- 最近作品：读取本地作品库，展示类型与相对时间，点击进入作品详情。
- 从灵感开始：展示精选模板，点击进入模板详情；右上角进入全部模板。

### 3.2 导入流程

- 工作室直接调用 `image_picker` 选图，不再强制经过上传页。
- 选图后底部弹层让用户选择「AI 风格迁移」或「图片编辑器」，并把图片字节直接带入目标页面。

### 3.3 风格迁移页

- 新增从相册选图/更换照片，解决「从首页或模板进入时没有源图」的断点。
- 支持通过路由预选风格：`/style-transfer?style=local-film`。
- 更换源图时清空旧成片与任务 id，避免新原图和旧成片拼在一起对比。
- 生成过程中禁用更换照片。

## 4. 数据与状态

- 新增 `recentCreationsProvider`（`autoDispose`）：首页和工作室共用最近 8 个本地作品，离开页面后释放，返回时重新读取。
- 新增纯函数 `filterTemplates` / `templateSearchText`，页面与测试共用，避免在 Widget 里堆业务判断。
- 模板收藏改为懒加载：先以空集合渲染，`SharedPreferences` 就绪后自动恢复；切换收藏时先等待初始化完成，避免初始化覆盖用户操作。
- 新增 `creationTypeLabel` / `creationTimeLabel`，统一作品卡片的类型与时间文案。

## 5. 验证

```powershell
cd apps/mobile
dart analyze lib test
flutter test --no-pub
```

结果：

- `dart analyze` 无新增问题，仅保留仓库原有的 3 条 `prefer_initializing_formals` info。
- `flutter test` 全部通过，新增覆盖：模板筛选/排序、收藏持久化、模板页搜索、工作室空态与最近作品。

## 6. 后续可继续做

- 模板资源化：把内置 mock 迁移为版本化本地 JSON，并支持远程增量更新。
- 最近创作合并后端历史：当前只读取本地作品库，后端模式下的历史作品还不会出现在首页。
- 工作室批量成片：在本地作品库和风格任务稳定后，再增加多选、队列和失败重试。
- 灵感首页深色模式：本次重点修复模板页，首页仍有部分白色卡片可继续统一为主题色。
