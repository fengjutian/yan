# 「颜」AI 影像创作应用需求文档

## 1. 产品定义

「颜」是一款面向 18～35 岁年轻女性的 AI 随身摄影师，将拍摄灵感、实时构图指导、AI 风格迁移、成片管理和社交分享整合为一条简单的创作流程。

产品主张：**今天，也值得被好好记录。**

核心指标：拍摄完成率、AI 成片率、作品保存率、分享率、7 日留存率。

## 2. 目标用户与场景

- 不熟悉摄影参数，希望快速拍出有氛围感照片的用户。
- 旅行、探店、穿搭、人像、美食、宠物及日常记录场景。
- 希望人物自然、风格统一，并快速发布到小红书、朋友圈、抖音或 Instagram 的用户。

## 3. 核心流程

1. 用户在“灵感”选择场景或直接打开相机。
2. 相机识别人物和场景，给出构图、机位、光线与姿势提示。
3. 用户拍照或从相册导入，可选择多张候选照片。
4. 工作室提供裁剪、校正、风格迁移、人物保护和效果强度调整。
5. 用户对比原图与效果，保存满意版本。
6. 分享工作台生成平台尺寸、封面、文案和标签，并调起系统分享。
7. 作品、草稿和收藏沉淀在个人空间。

## 4. 信息架构

底部导航固定为四项：

- **灵感**：今日推荐、场景模板、热门风格、最近创作。
- **相机**：中央主入口，拍照、构图线、水平仪和实时提示。
- **工作室**：导入照片、AI 风格迁移、批量成片、文生图入口。
- **我的**：作品、收藏、草稿、额度、设置。

## 5. 功能需求

### 5.1 灵感

- 按人像、旅行、探店、美食、宠物分类展示模板。
- 模板包含示例图、机位、站位、构图、姿势、推荐风格和示例文案。
- 点击模板可携带模板参数进入相机。
- 支持收藏模板，管理端可配置排序、状态和封面。

### 5.2 AI 相机

- 支持拍照、前后摄像头、闪光灯和相册导入。
- 支持三分线、中心线和对称构图辅助线。
- 提供水平线状态、人物站位和留白建议。
- 拍摄提示必须简短、非阻塞，并可关闭。
- MVP 使用设备端规则；后续版本增加人体关键点与实时视觉模型。
- 拍摄结果进入预览，可重拍或送入工作室。

### 5.3 AI 工作室

- 支持原图上传、裁剪、旋转、透视和水平校正。
- 支持胶片、日系、法式、港风、电影夜景、新中式、高级黑白等风格。
- 风格卡必须显示预览、说明和推荐场景。
- 支持风格强度、人脸保护、肤色保护、背景保护。
- 支持原图/效果滑动对比、撤销、重做和版本历史。
- 保留文生图及人物参考创作作为二级能力。
- 服务端任务类型扩展为 `STYLE_TRANSFER`、`IMAGE_EDIT` 和 `COMPOSITION_ANALYSIS`。

### 5.4 分享工作台

- 支持原尺寸、1:1、3:4、4:5、9:16 等平台尺寸。
- 支持多图排序、封面、拼图、留白和水印。
- AI 根据照片与用户语气生成标题、正文和标签。
- 支持复制文案、保存高清图和系统分享面板。
- 分享是导出能力；MVP 不建设关注、评论、私信等站内社区。

### 5.5 我的

- 作品、收藏和草稿分区。
- 每个作品保存原图、编辑版本、生成参数和创建时间。
- 游客自动创建匿名身份，不出现强制登录页。
- 游客数据保存在当前设备；绑定账号后可迁移至正式账号。
- 展示每日免费次数、会员额度及到期时间。

### 5.6 管理端

- 管理拍摄模板、风格包、分享模板、文本模型和图片模型。
- 模型配置包含服务商、Base URL、模型名、API Key、启用状态和连接测试。
- API Key 必须加密存储且不回显。
- 管理用户、额度、任务、失败原因和内容审核记录。
- 所有敏感配置与运营变更写入审计日志。

## 6. 额度与商业化

- 游客每日获得免费 AI 成片次数，按自然日恢复，不滚存。
- 基础拍照、构图线和本地编辑永久免费。
- AI 风格迁移、高清导出和批量处理消耗次数。
- 会员按月获得额度；支持单次次数包，但首版不接真实支付，只预留订单与套餐模型。
- 前端使用“剩余次数”，不向普通用户展示技术性积分概念。

## 7. 安全与隐私

- 上传前明确说明用途；用户可删除原图和全部衍生版本。
- 提示词与图片均经过内容审核。
- 默认不公开作品，不使用用户照片训练模型。
- API Key 使用 AES-256-GCM 加密存储。
- 分享前允许关闭位置、设备等元数据。

## 8. MVP 验收标准

- 首次启动通过“颜”字动画自动建立游客会话并进入灵感页。
- 用户可拍照或导入图片，并看到至少三种构图辅助线。
- 用户可选择至少六种带预览的风格，提交迁移任务并查看前后对比。
- 用户可保存成片、复制 AI 文案并调起系统分享。
- 每日额度准确扣减与恢复，失败任务不消耗额度。
- 管理员可配置并测试文本及图片模型，密钥不明文保存或返回。
- 核心接口具备鉴权、限流、内容审核、错误码和审计记录。

## 9. 开发阶段

1. **MVP 基础**：新导航、灵感首页、游客身份、相机与相册导入、构图辅助。
2. **AI 成片**：风格管理、风格迁移任务、强度与人物保护、前后对比。
3. **作品分享**：作品版本、收藏草稿、平台裁剪、文案生成与系统分享。
4. **商业运营**：每日额度、套餐订单模型、图片模型管理、审核后台。
5. **增强能力**：实时姿态指导、连拍优选、局部重绘和批量处理。
